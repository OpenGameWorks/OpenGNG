# CodeWarrior idioms: Loop shapes

Loop entry, rotation, padding and PArray/PList walks in CodeWarrior PS2 output, written as the source form that reproduces them. Each entry pairs an asm pattern seen in the original with the source that produces it, and names the function that proved it.

- A short loop whose original has `slti; nop; bnez; nop` (a nop before the loop branch) plus an extra nop after the loop matches only under `mwcps2-3.0-011126` / `-3.0.1-020123` (their short-loop padding), which in turn breaks large `global + offset` folding elsewhere. `#pragma padloop` does not reproduce it. Note `matches under 011126` in the DRAFT note and move on; do not spend attempts on the padding.
- `lw v1,i; addiu a0,v1,1; sw a0,i` followed by a compare on `a0` (no reload) is a pre-increment inside the condition: `(++arr->m_unk4 < arr->m_unk0) ? ... : 0` (`PMNode::CopyMNode`).
- A loop that tests the terminator both at entry and after the bottom read is `if (tag == 9) return 1; while (tag == 8) { ...; tag = 0; if (Read(&tag,4) != 4) return 0; if (tag == 9) return 1; } return 0;` (`PMNode::LoadBone`).
- The PArray walk advances with a ternary: `unsigned int i = m_nIdx + 1; m_nIdx = i; p = (i < m_nCount) ? m_ppData[m_nIdx] : 0;`. Spelled `p = 0; if (i < m_nCount) { p = m_ppData[m_nIdx]; }` it leaves an extra join `nop` before the loop's `bnez` and shifts every later branch (`src/game/EffectAPI.cpp`).
- A loop entered with a `b` to its bottom test that reads `count` twice (`sltu v0,$zero,v1` at the bottom, `sltu $at,$zero,v1` in the body) is a `for (unsigned int i = 0; i < arr.m_count; i++)` over a PArray whose body uses the inline bounds-checked read `(i < arr.m_count) ? arr.m_data[i] : 0` (`Pickup::SoulSuckerInRange`).
- A list walk that stores a cursor at `list+0xC` (`cur==0 → head->item`, else `cur->next`) is the inline `PList::GetFirst()`/`GetNext()` from `PList.h`: `for (p = (T *)list.GetFirst(); p; p = (T *)list.GetNext())`. Hand-written cursor code does not match (`CameraCutManager::GetNextCutCamera`).
- A PArray walk (count at +0, cursor at +4, storage at +8: `sw $zero,cur; lw cnt; beqz; lw data; b; lw 0(data); daddu a0,zero`, then `cur+1; sw; sltu; beqz; daddu a0,zero; lw cur; sll 2; addu; lw`) is `for (p = (T *)(cnt != 0 ? data[0] : 0); p != 0; p = (T *)(++cur < cnt ? data[cur] : 0))` with `cur = 0;` before it (`Interface::DeleteMeshLayer`).
- When the element type of a PArray walk differs from the storage type, cast the whole ternary, `p = (T *)(i < cnt ? data[cur] : 0);`. Casting one arm changes the code (`EntityManager::Animate`).
- An index loop whose original recomputes `sll i,2` each pass while ours keeps a strength-reduced byte offset in an extra saved register (frame 0x10 larger, `this` one register higher) comes from a unit built with strength reduction off. `#pragma opt_strength_reduction off` after the header lines restores it; the `-opt` command-line spellings have no effect. The pragma applies file-wide, so report the candidate to the coordinator, who scans every tag of the file with `src/scratch/pragmascan.py` before adding it (`PCutScenePlayer.cpp`).
- A for-loop entry test is `sltu $at,$zero,n; beqz $at`; a `do`-while guarded by `if (n != 0)` gives `beqz n` instead (`PCutScenePlayer::KillActorFx`, `Render`).
- A loop guard whose delay slot holds the counter init while the byte-offset init sits on the fall-through path is `unsigned int i = 0; if (i < n) { unsigned int nOffset = 0; do { ... nOffset += SIZE; } while (++i < n); }` (`PWorld::AttachFxTriggersToNodes`).
- A loop the original enters with `b` to a test at its bottom (often `nop` before the test), where ours tests at the top and branches back with `bnez`, is a goto-entered loop: `i = 0; goto test; loop: body; i++; test: if (i < n) goto loop;` (sound.c SOUND_CountFreeSPUChannels, HudHint::EnableBG). `for`, `while`, `do`/`while` and a `goto` into a `do` all rotate the test to the top.
- `-O4,p` enters a `while`/`for` loop with a `b` to its bottom test. A PArray walk whose tail picks the next element compiles from a ternary, `pNode = (idx < m_unk0) ? m_unk8[m_unk4] : 0;`; the same `if`/`else` leaves an extra `b` and `nop` (`FontManager::EnableAllText` in `src/game/Font.cpp`).
